# Site Survey Worksheet

Use this once per building before or during setup. Every number entered in Pratibimb's Setup page comes from here, so the twin starts from facts, not guesses.

**Rules:** never photograph people. Photograph only device nameplates, ceilings for the AI Surveyor, and empty corridors. Pace room sizes (one adult step is about 0.75 m) if a tape is not available.
